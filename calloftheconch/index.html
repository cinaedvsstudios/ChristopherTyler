CALL OF THE CONCH

INTERACTIVE STORYTELLING / CUTSCENES / ASSET PRODUCTION

Call of the Conch is an ongoing underwater adventure game combining exploration, storytelling, characters and a larger interactive fantasy world.

I develop the visual assets used throughout the game, including characters, environments, interface elements and cinematic sequences. The videos shown in this portfolio are cutscenes created for use inside the game, helping establish story, character and atmosphere between playable sections.

Because the project is designed as a larger connected experience, the visual material needs to work across gameplay, cinematics and interface rather than as individual standalone images. This requires consistent world-building, reusable assets and thinking about how one sequence leads into the next.

Deliverables

Game cutscenes · characters · environments · UI · animation · interactive assets

Focus

Sequence design · world-building · visual continuity · reusable assets · interactive storytelling
